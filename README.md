# Holiday Arena

Mobile-first idle PvP RPG arena game.

## V1 Features

- Login / Register system
- Character selection screen
- Max 4 character slots
- Character creation
- Class system
  - Warrior
  - Assassin
  - Mage
  - Ranger
  - Paladin
- Character power system
- Arena matchmaking foundation
- Leaderboard foundation

## Planned Systems

### Progression
- Quest system
- XP and level system
- Loot chest rewards
- Gear rarity
- Gear upgrade system

### PvP
- Auto battle arena
- Elo ranking
- Match history
- Arena rewards

### Social
- Friends
- Seasonal ranking
- Global leaderboard

## Tech Stack

Frontend:
- React
- Vite
- TailwindCSS
- Framer Motion

Backend:
- Supabase
