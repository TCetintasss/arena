# Holiday Arena V1

## Kurulum

```bash
npm install
npm run dev
```

## Netlify

Build command:

```bash
npm run build
```

Publish directory:

```bash
dist
```

- Karakter oluşturma
- Warrior, Assassin, Mage, Ranger, Paladin class seçimi
- Aktif karakter profil ekranı
